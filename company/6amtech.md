In my first month as a Software Engineer at 6amtech, I've had an extensive experience involving multiple products and technologies. I was very fortunate to be part of the 6amtech team. This is not just a team but a family with a mind-free culture and environment. Here are some experiences I'd like to share:

## Features and Technologies
Search, cart, checkout, details, code patterns analysis and improvements, Figma to Flutter implementation, Responsive UI components (web, mobile), Multiple image uploads API, GetX, Bloc with code generation, CustomScrollView, API Integration, Git & Github, Go Router, Code review process and company coding standards and many more.

As a first month employee, I did not expect to learn as much as I needed to and work around it. This was not just keywords - all of this was like a big book with code implementations. But with all this, I also had a lot of time to walk around the office, play games, and drink coffee. I was also fortunate to be part of the 5-year anniversary of 6amtech and enjoyed that exciting day. Here are some pictures from that day below:
